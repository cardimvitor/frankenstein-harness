# Frankenstein Harness

A coding-agent harness (CLI/TUI plus local browser UI) combining ideas from DeepSeek Harness (dsh) and Qwen Code, tuned for a single model: Qwen3.8 27B on a self-hosted vLLM with MTP=3.

Status: planning and discovery. See [docs/DESIGN.md](docs/DESIGN.md).
